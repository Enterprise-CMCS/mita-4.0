MITA State Self-Assessment

Meet the MITA SS-A Tool

The MITA 4.0 SS-A Tool gives states a practical way to document assessment results, organize maturity work, and prepare the outputs needed for reporting and planning.

Open the Tool Visit the Tool Site See Where It Fits

Tool Overview

What the tool does

The MITA 4.0 SS-A Tool is a browser-based application designed to help State Medicaid Agencies carry out the MITA State Self-Assessment in a more structured way. It supports assessment work across 75 capability areas and the five ORBIT dimensions.

Who it is for

It is built for State Medicaid Agencies, especially the staff responsible for self-assessment, Medicaid IT planning, architecture, and documenting maturity results.

What makes it useful

Instead of tracking results across disconnected notes and spreadsheets, the tool gives teams one place to work through capability areas, capture notes, and prepare exports.

How it supports MITA 4.0

It helps the Step 4 State Self-Assessment become more operational by organizing findings and producing outputs that can feed leadership review, roadmap planning, and CMS-facing reporting.

Key takeaway

A tool for documenting the assessment, not replacing the framework

The MITA 4.0 framework still defines the overall process. The SS-A Tool helps states capture and package the maturity assessment work in a more practical format.

How It Works

A simple three-part workflow

The tool is designed to guide users from selecting a capability area to capturing ratings and exporting results.

1

Select a capability

Start from the Dashboard and choose the capability area you want to assess. The tool organizes the work across the available domains and capability areas.

2

Rate the ORBIT dimensions

Work through guided questions, enter notes, and document maturity across the five ORBIT dimensions for the capability you are reviewing.

3

Export the results

When the work is ready, generate outputs for reporting and backup, including formats that support CMS submission and internal review.

Features

What users can expect

Dashboard

Browse capability areas and see how assessment work is organized across the tool.

Results

Review and summarize assessment outcomes in one place.

Import/Export

Generate PDF reports, CSV outputs for CMS-related use, and ZIP backups to preserve the work.

Guide

Use the built-in guide for step-by-step help and onboarding.

Notes and evidence

Add notes and supporting detail as the team works through each capability area.

Tags and backups

Organize work in progress and create backups so teams can protect their progress over time.

Privacy first

Assessment data stays in the browser rather than being sent to an external server.

Works offline

After the initial load, teams can keep using the tool even without a live internet connection.

Open source

The tool is free to use and does not require a state to set up a separate account-based platform.

Where It Fits

How the tool fits into MITA 4.0

The SS-A Tool is most useful once a state has already identified the outcomes, capabilities, and architectural context it wants to assess.

Before the tool

Use MITA 4.0 to define the assessment context

Complete the earlier planning work so the state understands the business challenge, targeted outcomes, and relevant capabilities.

In the tool

Capture maturity findings in a consistent way

Use the tool to document the actual maturity ratings, working notes, and exported outputs for the State Self-Assessment.

After the tool

Turn the results into leadership decisions

Use the outputs in the SS-A Executive Summary, roadmap review, and prioritization work that follows the assessment.

Best use case

The tool is especially helpful for teams that want a cleaner, more repeatable way to document the State Self-Assessment and prepare outputs for review, reporting, and continuity.

Get Started

Use the tool when your team is ready to document the SS-A

If you are planning the assessment sequence, use the MITA 4.0 implementation walkthrough first. If you are ready to capture maturity findings, open the official SS-A tool site.
